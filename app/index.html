Try it
  1. Press Dial code (it dials *384*2026#).
  2. Type your question straight in and press Send, for example majani yana unga wa njano chini ("yellow powder under the leaves"). Or type 2 for the price, 3 for a person.

Or press SMS to text the question, or Voice call to hear the answers (for farmers who prefer listening to reading).

The 10 second rule

A USSD session drops if the reply takes more than about 10 seconds. Big AI models in the cloud can take several seconds to answer, which is risky. This small model answers in a few milliseconds, so even on a slow 2G network the reply arrives with plenty of time to spare. The bar under the phone shows each reply's time.

Why a second phone

Many farmers have a basic phone that can't install apps. It can still dial a short code (USSD) or send an SMS, which need a phone signal but no internet or data. The same AI and the same expert answers reach them that way.

This screen runs the same code a real USSD code or SMS number would run (it is in the project as a ready server), so what you see here is what the farmer's phone would get. The code shown is a placeholder.

About this demo: everything runs in this browser tab. Your questions are kept only in this tab and are gone when you close it; nothing is sent anywhere, and "sent by SMS" is simulated. The consent screen shows what a farmer would see in real use.
The AI never writes advice: it only picks from answers written by people from coffee research sources. When it isn't sure, it says so and passes the question to a person. Prices are a reference, not an offer: the farmer decides. The Kiswahili text is a draft translation still to be checked by a native speaker. · Code (MIT)
